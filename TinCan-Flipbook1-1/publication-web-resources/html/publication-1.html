The Metaphor, Kicks!

The Tin Can

xAPI: A Single, self-contained record of an action.

Kicking the Can

An Activity: A learner interacting with an app, website, or a real task. The action triggers the creation o an xAPI statement.

Down the Road

This is the Learning Record Store (LRS): Where the statement is sent. The LRS collects all the different cans from many sources.

Kicking it further

Representative of other systems: Like a Learning Management System (LMS), or a dashboard. These can access the LRS, pull out a few cans (actions), and use the data for analy-sis reporting.

The Application of xAPI allows your learning data to be portable and reusable.

The Language of xAPI

High Tech High Jinx

xAPI requires a special language to function, called JSON (JavaScript Object Notion). This language is used for writing xAPI Statements, a file format that provides its structure.

It might seem ominous, but writing JSON for xAPI is simple. Consider the paradigm: “Actor did Verb to Object.” This sen-tence with JSON language provide the blueprint for how the sentence structure is written.
